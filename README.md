 # Aumbre - Restaurant Website
This is a restaurant website i built using React.js. It has a dark, moody theme with green and cold colours.

# What i used to built it 
React.js
React Router ( to move between pages without reloading)
React Icons( social media etc)
Plain css used (no Bootstrap or Tailwind)
Google fonts for the text styles

# Pages in the website
1. Home
2. About
3. Menu
4. Chefs
5. Gallery
6. Reservations
7. Testimonals
8. Blog
9. Faq
10. Contact
11. Page not found 404

# What website can do
Has a menu bar that stays at the top when yoy scroll
For small screen hamburger icon is used
Each page has its own title which helps with SEO
The FAQ page opens and closes answer when you click a question


# Structure of the folder

assets> images and icons
components> all the resuable pieces (Navbar, Footer etc)
data > the actual content (menu items, chefs , FAQ etc)
hooks > Small resuable code logic
pages > the 11 pages of the website
App.jsx > controls which page show for each url
main.jsx > the starting point of the app


# How to run this project on your computer

1. Download or clone this project
2. Open the folder in terminal
3. Type "npm install" to install everything the project needs
4. Type "npm run dev" to start the project
5. Open the link it gives you in your browser usually `http://localhost:5173`
